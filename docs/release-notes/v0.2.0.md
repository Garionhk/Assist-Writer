# Assist Writer 0.2.0

First public release. Assist Writer is a private AI writing assistant for English and Traditional Chinese. The AI runs on your own PC through Ollama, so your writing never leaves your computer.

## Downloads

| File | What it is |
|---|---|
| `AssistWriter-Setup-0.2.0.exe` | **Installer (recommended).** Start menu and desktop shortcuts, opens `.awd` files. |
| `AssistWriter-Portable-0.2.0.exe` | The app as one file; runs without installing. |
| `AssistWriter-Web-0.2.0.zip` | Web version for using it from other devices on your network. |

Windows 10 or 11, 64-bit. The files aren't code-signed, so SmartScreen may warn the first time: **More info → Run anyway**.

## Before you install

The AI models need graphics card memory (VRAM):

- **16 GB recommended**: checking while you type and rewriting whole documents both run at full speed.
- **8 GB minimum**: checking while you type is fast; rewriting whole documents is slower.
- With less memory, or without a graphics card, everything works, but slowly.

You'll need about 24 GB of disk space for Ollama and the two default models. On first start, Assist Writer's **Setup** window installs Ollama and downloads the models for you.

## What's in it

- Live grammar and style checking, with every change confirmed before it's applied.
- Improve a selection, or Rewrite a whole document, in a chosen writing style (ten built in, plus your own).
- Formatting kept through AI changes, even translations.
- Change history with undo of any single AI change.
- Editor with fonts, headings, lists, zoom, and images with Word-style text wrapping and alignment.
- Opens and saves Word files with their formatting and images; exports PDF, Word, RTF, Markdown and text.
- English or Traditional Chinese interface.
- Starts Ollama when needed and frees its graphics memory when you close the app.
